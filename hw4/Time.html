Time API

Constructors

Constructor Description
Time() Construct a Time object with default 00:00:00
Time(int hour) Construct a Time object with [hour]:00:00
Time(int hour, int minute) Construct a Time object with [hour]:[minute]:00
Time(int hour, int minute, int second) Construct a Time object with [hour]:[minute]:[second]
Time(Time time) Construct a Time object by copying an existing Time object

int getSecond() Returns the second field
void setSecond(int second) Sets the second field to the given value
